# 拼豆色板 PDF 后续处理

当前项目使用 `server/app/palette.py` 中的临时示例色板。

收到真实拼豆色号 PDF 后，建议新增脚本：

1. 读取 PDF 文本和表格内容。
2. 提取颜色编号、颜色名称、RGB。
3. 校验 RGB 是否为三个 `0-255` 数值。
4. 输出为项目色板结构：

```json
{
  "code": "05",
  "name": "Red",
  "rgb": [205, 35, 45],
  "enabled": true
}
```

如果 PDF 中缺少 RGB，可先提取色号和名称，再通过人工或品牌官方资料补齐 RGB。
